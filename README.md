# Emparentar y Renombrar Inteligente — Extension Repository

Native Blender 4.2+ repository. Current release: **3.6.1**.

Add this URL in Blender's Get Extensions > Repositories > Add Remote Repository:

https://raw.githubusercontent.com/SaulOscuro/Emparentar_Renombrar_Operador/codex/extension-repository/stable/index.json

3.6.1 adds black, lampmetal and lampemission to the supported parenting and overlay families. Primitive remains a red warning. Version 3.6 introduced selection names, all-object names and unsupported-name warnings.

Source and build instructions: [main branch](https://github.com/SaulOscuro/Emparentar_Renombrar_Operador/tree/main).
